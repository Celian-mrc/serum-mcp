# Real-Serum test log

Running record of what this project has actually verified by loading a
generated/edited `.SerumPreset` in real Serum 2 (FL Studio 21 host), versus
what only passes the automated `scripts/check_preset.py` scan and unit
tests. Both matter, but they catch different failure classes — see
`CONTRIBUTING.md`'s "Evidence standard" and the `test-in-serum` skill for
why the distinction is load-bearing (the project's first fully-tested
preset still crashed FL Studio from a bug no round-trip check caught).

Update this file whenever a feature crosses from "written + unit-tested"
to "loaded in real Serum and confirmed" — or when a live load surfaces a
bug, note that too, since a fixed-after-live-testing feature is stronger
evidence than one that merely round-trips.
